# 客户日报归档

面向客户的工作日报存放于此，不写技术实现细节。

## 文件约定

- 路径：`docs/daily-reports/`
- 命名：`YYYY-MM-DD.md`（按工作日日期）
- 若同一天有多份：`YYYY-MM-DD-补充说明.md`

## 写作提示（给后续助手）

写新日报时请：

1. 新增 `YYYY-MM-DD.md`，并更新本表「已归档」
2. 面向客户、少术语；用业务结果表述「做了什么 / 带来什么」
3. 结构建议：概述 → 完成内容 → 下一步计划
4. 可参考已有日报语气与粒度
